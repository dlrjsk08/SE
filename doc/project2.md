### (1) 사용자의 기대치
* **신뢰성:** 학교 인증을 통해 사기 걱정 없는 안전한 거래 환경 제공
* **사용성:** 직관적인 UI/UX로 교육 없이도 즉시 검색 및 판매글 작성 가능
* **효율성:** 찾는 책이 등록되었을 때 지연 없는 실시간 알림 서비스 제공
* **무결성:** 채팅 및 개인정보, 거래 내역에 대한 철저한 보안 유지

### (2) 개발자 및 유지보수자의 기대치
* **유지보수성:** 기능 확장 및 버그 수정 시 기존 코드 영향도를 최소화하는 구조적 설계
* **이식성:** 모바일 앱 전환이나 클라우드(AWS/GCP) 환경 이전이 용이한 설계
* **검사 가능성:** 업데이트 배포 전 정상 작동 여부를 빠르게 테스트할 수 있는 자동화 환경
* **이해 가능성:** 코드와 README 문서만으로도 새로운 개발자가 즉시 파악 가능한 명확성

### (3) 개발 조직 관리자의 기대치
* **상호운용성:** 학교 메일 서버 및 외부 지도 API 등과의 매끄러운 연동
* **확장성:** 학기 초 트래픽 급증 시에도 서버 다운 없이 리소스를 유연하게 조절
* **준수성:** 개인정보보호법 및 학교 보안 규정의 철저한 준수
* **안정성:** 배포 이후 치명적 오류 없이 서비스가 지속되는 높은 가용성 확보
