# 프로젝트 관리 계획서

## 1. 서 론

### 1.1 문서 목적 및 범위
본 프로젝트 계획서는 **클라우드 파일 공유 시스템 (Mini Drive)**에 대한 전반적인 내용을 정리하여 프로젝트를 진행하는 데 있어 각 세부 사항의 지표로 삼는 것을 목적으로 한다.

본 문서는 다음과 같은 범위의 지표로 적용할 수 있다.
1. 프로젝트 개요 (프로젝트 정의, 주요 기능 정리)
2. 개발 계획 및 환경 (개발 절차 모형, 내용 및 일정, 소프트웨어/하드웨어 환경)
3. 팀 구성 (팀 구조/역할 및 책임)
4. 품질관리 (팀 미팅, 변경 사항 및 산출물 관리)
5. 산출물 (산출물 정의, 작성일 및 담당자)

### 1.2 프로젝트 개요

#### 1.2.1 프로젝트 정의
사용자가 장소에 구애받지 않고 파일을 안전하게 업로드, 보관 및 공유할 수 있는 클라우드 기반의 파일 관리 시스템을 구축한다.

#### 1.2.2 주요 기능 설명
| ID | 설명 |
| F01 | 사용자 인증 및 권한 관리 (회원가입, 로그인, JWT 보안) |
| F02 | 파일 및 폴더의 생성, 수정, 삭제, 이동 등 계층적 관리 기능 |
| F03 | AWS S3 연동을 통한 안정적인 대용량 파일 업로드 및 다운로드 |
| F04 | 파일별 공유 링크 생성 및 사용자별 접근 권한(읽기/쓰기) 설정 |
| F05 | 사용자별 스토리지 사용량 시각화 및 파일 검색 기능 |

### 1.3 프로젝트 목표
사용자에게 직관적인 파일 탐색 경험을 제공하고, 데이터의 무결성과 보안이 보장된 클라우드 스토리지 환경을 구축한다. 웹 브라우저를 통해 언제 어디서든 자신의 파일에 접근하고 타인과 효율적으로 협업할 수 있는 서비스를 제공한다.

### 1.4 용어 정의
| 용어 | 설명 |
| :--- | :--- |
| AWS S3 | 아마존 웹 서비스에서 제공하는 온라인 객체 스토리지 서비스 |
| JWT | 당사자 간에 정보를 JSON 개체로 안전하게 전송하기 위한 개방형 표준 |
| API | 클라이언트와 서버가 데이터를 주고받기 위해 정의된 인터페이스 |

## 2. 개발 계획

### 2.1 개발 절차 모형
1. **소프트웨어를 개발하기 위한 개발 절차 모형**
   - 요구사항이 구체적이며 단계별 승인이 중요한 프로젝트 특성을 고려하여, 각 단계가 순차적으로 완료된 후 다음 단계로 넘어가는 **폭포수 모형(Waterfall Model)**을 채택하였다. 이를 통해 프로젝트의 안정성과 문서화의 완성도를 높인다.
2. **개발 절차 모형과 함께 분석, 설계를 진행하기 위한 방법론**
   - 시스템의 확장성과 유지보수 용이성을 위해 객체지향 방법론을 채택하였다. 파일, 폴더, 사용자 등의 요소를 객체 단위로 모듈화하여 개발 효율성을 극대화한다.

### 2.2 WBS (Work Breakdown Structure)
- **요구분석:** 프로젝트 계획 수립, 클라우드 시장 조사, 기능 정의 및 요구사항 명세 작성
- **설계:** 시스템 아키텍처 설계, DB ERD 작성, API 가이드라인 및 UI 와이어프레임 설계
- **코딩:** 백엔드 서버 구축, AWS S3 스토리지 연동, 프론트엔드 UI 및 기능 구현
- **테스트:** 단위 기능 테스트, 전체 시스템 통합 테스트, 최종 버그 수정 및 배포

### 2.3 개발 활동
| 개발 활동 | 설명 |
| :--- | :--- |
| 프로젝트 요약 | 프로젝트 전체 요약서 작성 |
| 프로젝트 계획 | 프로젝트 관리 계획서 작성 |
| 요구사항 정의 | 요구사항 정의서 및 기능 명세서 작성 |
| 요구사항 분석 | 상세 요구사항 분석서 및 유스케이스 작성 |
| DB 설계 | 엔티티 정의 및 데이터베이스 스키마 설계 |
| API 설계 | RESTful API 엔드포인트 및 데이터 포맷 정의 |
| 시스템 구현 | 백엔드 및 프론트엔드 소스 코드 작성 |
| 통합 테스트 | 전체 기능 간의 상호작용 검증 및 오류 수정 |
| 완료 보고 | 프로젝트 최종 산출물 정리 및 완료 보고서 작성 |

### 2.4 개발 일정
*(6주 개발 일정 기준)*
- 1주차: 요구사항 분석 및 프로젝트 계획 수립
- 2주차: 시스템 설계 (DB, API, UI)
- 3~4주차: 백엔드 서버 및 파일 스토리지 연동 구현
- 5주차: 프론트엔드 인터페이스 개발 및 API 연동
- 6주차: 통합 테스트, 디버깅 및 시스템 배포
